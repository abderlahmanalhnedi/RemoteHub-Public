# Screenshot Assets

The five PNG files in this directory were captured from the RemoteHub
application at 1440×960 pixels and reviewed at full resolution for public use.

They contain only synthetic profiles, demo usernames, a reserved test domain,
and a localhost-only disposable SSH endpoint. The host-key fingerprint belongs
to that disposable endpoint. The images contain no real credentials, private
keys, private addresses, internal DNS names, personal paths, customer data,
notifications, Dock, Finder sidebar, or unrelated desktop content.

The screenshots are used by
[`getting-started.md`](../../user-guide/getting-started.md).

Future screenshots must receive the same full-resolution review before being
committed. Never include real credentials, private infrastructure, terminal
history, local filesystem paths, or unrelated desktop content.
